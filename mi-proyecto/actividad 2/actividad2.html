What is HTML?

HTML is a the standard lenguage for creating or giving structure to web pages or web apps

Explain the head and the body tags.

The head tag is used as a container for metadata. Metadata is the data from our html doc which may include the title, styles, scripts, etc. (W3Schools, s.f.). As for the body tag, it is used to contain all the content you wish to display on your website. this can go from images, text, videos, etc.

Explain the section, article, aside, header, footer tags

The section tag defines a thematic group of content. Is used to organize related content into blocks.to create defined sections in our webpage
Article tag is a tool for accessibility and SEO, as it provides semantic meaning to browsers, screen readers, and search engines
Aside tag represents a portion of a document whose content is only indirectly related to the document's main content. Asides are frequently presented as sidebars or call-out boxes
Header represents introductory content, It may contain some heading elements but also a logo, a search form, an author name, and other elements
Footer is a section appearing at the bottom of the page where we can find copyright information, contact info, etc

What is CSS?

Is a language used to provide styles for our web pages

What is the purpose of CSS?

Its purpose is to provide aesthetic to web pages allowing to change the font, colors, layout, etc

How do you apply CSS to an HTML document?

You can apply CSS: inline, by creating an aside .css document and link it to your html, and finally by using a style tag in your html document

What is a selector and what is a CSS rule?

A selector is what indicates which elemnt or elements CSS is going to style, and a CSS rule is the block that define the style we are applying to the element or elements we selected

Explain a tag, class, and id selector

Tag is used to select ALL elements of an especific type. A class selector is used to select elements with an especific class name. We can combine tag and class selector to change the style of an especific element within a class. Finally the id selector can change the style of an element with an especific id

What is a class? What is an id? How are they related to CSS?

A class is an attribute that can identify one or more elements. Then an ID is an attribute that identifies a single element. Both of them are used in CSS to select elements and apply styles to them.

Explain the CSS Box Model? Show an example.

The CSS Box Model is the layout structure that defines how every HTML element is displayed as a rectangular box on a webpage. It consists of four layers: the content, padding, border, and margin. The content is the actual text or image inside the element.

Explain the media querries

Media queries are a CSS feature that allows you to apply styles based on the screen size, device type, or other conditions. They are mainly used to make websites responsive, meaning the layout can adapt to different devices like phones, tablets, and desktops.

Explain the display: grid and display: flex properties

grid is used to create two-dimensional layouts, meaning it controls both rows and columns at the same time. It allows you to place elements into a grid structure and precisely control their position, spacing, and alignment. And the flex property is basically the same but for one-dimensional layouts
